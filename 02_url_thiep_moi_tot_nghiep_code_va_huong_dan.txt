FILE URL THIỆP MỜI — CODE + HƯỚNG DẪN LẤY URL PUBLIC
======================================================

Lưu ý quan trọng
----------------
Mình chưa thể tự publish trực tiếp lên tài khoản Vercel/Netlify/GitHub của bạn từ trong cuộc trò chuyện này, nên chưa thể tạo ra một URL public thật ngay lập tức.
Tuy nhiên, nội dung bên dưới là code thiệp mời hoàn chỉnh. Bạn chỉ cần lưu thành file index.html rồi deploy là sẽ có URL dạng:

- Vercel: https://ten-project-cua-ban.vercel.app
- Netlify: https://ten-site-cua-ban.netlify.app
- GitHub Pages: https://username.github.io/ten-repo

Cách nhanh nhất để có URL
-------------------------
Cách 1: Netlify Drop, không cần code nhiều
1. Tạo một thư mục tên graduation-invitation.
2. Tạo file index.html trong thư mục đó.
3. Copy toàn bộ code HTML ở phần dưới vào file index.html.
4. Vào Netlify Drop.
5. Kéo thả cả thư mục graduation-invitation vào trang Netlify Drop.
6. Netlify sẽ cấp ngay một URL public.

Cách 2: Vercel
1. Tạo repo GitHub mới, ví dụ graduation-invitation.
2. Upload file index.html lên repo.
3. Vào Vercel > Add New Project > Import repo.
4. Framework Preset chọn Other.
5. Deploy.
6. Sau khi deploy xong, Vercel sẽ cấp URL public.

Cách 3: GitHub Pages
1. Tạo repo GitHub tên graduation-invitation.
2. Upload file index.html.
3. Vào Settings > Pages.
4. Source chọn Deploy from a branch.
5. Branch chọn main, folder chọn /root.
6. Save và chờ GitHub tạo URL.

    const eventDate = new Date("2026-06-16T07:00:00+07:00").getTime();

    function updateCountdown() {
      const now = new Date().getTime();
      const diff = eventDate - now;

      if (diff <= 0) {
        document.getElementById("days").textContent = "00";
        document.getElementById("hours").textContent = "00";
        document.getElementById("minutes").textContent = "00";
        document.getElementById("seconds").textContent = "00";
        return;
      }

      const days = Math.floor(diff / (1000 * 60 * 60 * 24));
      const hours = Math.floor((diff / (1000 * 60 * 60)) % 24);
      const minutes = Math.floor((diff / (1000 * 60)) % 60);
      const seconds = Math.floor((diff / 1000) % 60);

      document.getElementById("days").textContent = String(days).padStart(2, "0");
      document.getElementById("hours").textContent = String(hours).padStart(2, "0");
      document.getElementById("minutes").textContent = String(minutes).padStart(2, "0");
      document.getElementById("seconds").textContent = String(seconds).padStart(2, "0");
    }

    setInterval(updateCountdown, 1000);
    updateCountdown();
